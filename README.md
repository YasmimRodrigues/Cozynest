# 🧶 Cozynest

**Cozynest** is an e-commerce storefront web page designed for a vintage shop featuring handmade fashion, accessories, candles, and unique artisanal items. Built to practice and refine skills in **Tailwind CSS**, this project showcases a cozy, autumn-inspired aesthetic paired with modern UI layouts.

---

## 🚀 Built With

- **HTML5** — Semantic page architecture.
- **Tailwind CSS** — Utility-first CSS framework for custom styling, grids, and responsive components.
- **JavaScript (Vanilla)** — DOM interactions and dynamic interface elements.

---

## 🎨 Key Features & Technical Highlights

- **Hero Banner:** Welcoming hero section with brand taglines, call-to-action buttons, and brand partner logos.
- **Category Grid:** Visual categories showcasing products like *Clothings*, *Candles*, *Accessories*, *Clocks*, and *Bags*.
- **Featured Banners & Blog Highlights:** Sections tailored for marketing stories, workshops, and artisan insights.
- **Product Showcase & New Arrivals:** Clean product cards featuring prices, tags, discount banners, and quick view options.
- **Customer Reviews:** Testimonial cards featuring ratings, customer feedback, and purchased items.
- **Responsive Layout:** Adaptive design using Tailwind breakpoints to ensure a seamless experience across all device sizes.
